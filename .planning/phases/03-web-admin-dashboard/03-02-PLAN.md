Add to `admin_dashboard/router.py`:

1. `GET /keys` — `Depends(require_admin)` — call `await admin_service.list_key_groups()`, render `keys.html` passing `key_groups` list.

2. `POST /keys/{group_name}/{key_name}/save` — `Depends(require_admin)` — accept `value: str = Form(...)`. Validate: `value` must not be empty (return 400 or re-render card with error if blank). Call `await admin_service.set_api_key(key_name, value, admin_id=admin_id)`. Call `await send_admin_notification(f"API key {key_name} updated via web by admin {admin_id}")`. Re-fetch the updated group: `group = await admin_service.get_key_group(group_name)`. Return `TemplateResponse(request=request, name="partials/key_group.html", context={"group": group})`.

3. `POST /keys/{group_name}/{key_name}/delete` — `Depends(require_admin)` — call `await admin_service.delete_api_key(key_name)`. Call `await send_admin_notification(f"API key {key_name} deleted via web by admin {admin_id}")`. Re-fetch group and return updated `partials/key_group.html` fragment.

Create `admin_dashboard/templates/keys.html`:
- Extends base.html. Title: "API Keys".
- Page heading + brief description ("Manage provider API keys. Values are write-only — existing keys show as 'Set'.").
- Loop over `key_groups`: `{% for group in key_groups %}{% include "partials/key_group.html" %}{% endfor %}`.
- Include a link/anchor to each group for large-page navigation.

Create `admin_dashboard/templates/partials/key_group.html`:
- Outer div: `id="key-group-{{ group.group_name }}"` — this is the HTMX swap target.
- Group header: `group.group_name` as title, overall status badge ("All set" green / "Missing keys" red).
- For each key in `group.keys`: show key name and status (`"Set"` or `"Not set"` — NEVER the actual value).
- Save form per key:
  ```html
  <form hx-post="/admin/keys/{{ group.group_name }}/{{ key_name }}/save"
        hx-target="#key-group-{{ group.group_name }}"
        hx-swap="outerHTML">
    <input type="password" name="value" placeholder="Enter new value" autocomplete="off" value="">
    <button type="submit">Save</button>
  </form>
  ```
- Delete button per key (only shown if key is set):
  ```html
  <button hx-post="/admin/keys/{{ group.group_name }}/{{ key_name }}/delete"
          hx-target="#key-group-{{ group.group_name }}"
          hx-swap="outerHTML"
          hx-confirm="Delete this key?">Delete</button>
  ```
- Input `value=""` is always empty — never pre-populated.
  </action>

4. `POST /tags/add` — `Depends(require_admin)` — accept `tag: str = Form(...)`. Validate non-empty. Call `await admin_service.add_tag(tag, admin_id=admin_id)`. Send notification. Return `TemplateResponse(request=request, name="partials/tag_row.html", context={"tag": new_tag})` — HTMX will prepend or append this into the table body using `hx-target="#tag-table-body" hx-swap="beforeend"` on the form.

5. `POST /tags/{tag_id}/remove` — `Depends(require_admin)` — call `await admin_service.remove_tag(tag_id)`. Send notification. Return `HTMLResponse("")` with status 200 — HTMX will delete the row via `hx-swap="outerHTML"` swapping to empty content.
