  <action>
    Create web_app/router.py -- FastAPI APIRouter with routes. This task depends on Task 1's scaffold being in place.

    - `GET /` -- Homepage. Renders `home.html` template. Accepts `?lang=he|en` query param (default `he`), sets lang cookie.
    - `POST /upload` -- Accepts `UploadFile`, validates: max 10MB, content_type starts with "image/". On failure return HTML error fragment with appropriate status code. On success: generate session_id via `secrets.token_urlsafe(16)`, store bytes in module-level `_pending: dict[str, bytes]` dict, return `partials/progress.html` template with session_id and a base64 thumbnail (resize to 96px with Pillow in executor, matching Phase 1 pattern). Apply `@limiter.limit("10/hour")` decorator.
    - `GET /stream/{session_id}` -- SSE endpoint. Returns `StreamingResponse` with `media_type="text/event-stream"` and headers `Cache-Control: no-cache`, `X-Accel-Buffering: no`, `Connection: keep-alive`. The async generator:
      1. Pops bytes from `_pending[session_id]` (yield error event if missing)
      2. Yields `event: progress` with "Analyzing photo..." HTML
      3. Calls `from providers.manager import analyse_image` (lazy import); then `winner, _ = await analyse_image(data)` -- NOTE: analyse_image returns `tuple[ProviderResult, list[ProviderResult]]`, NOT a list. Extract products via `products = winner.to_product_info_list()`.
      4. Yields `event: progress` with "Found N products..." HTML (where N = len(products))
      5. For each product, calls `amazon_search.search_amazon(product)` to get list[AmazonItem]. Collect as `all_results: list[list[AmazonItem]]`.
      6. Yields `event: progress` with "Searching Amazon..." HTML
      7. Calls `image_annotator.annotate_products(data, products)` in executor (CPU-bound, use `asyncio.get_event_loop().run_in_executor(None, ...)`)
      8. Calls `search_store.save_web_search(data, annotated_bytes, products, all_results)` to persist results
      9. Yields `event: done` with the redirect URL `/search/{short_id}`
    - `GET /search/{short_id}` -- Stub route for now (Plan 02 will implement full rendering). Returns basic HTML confirming results loaded, or 404/410 for missing/expired.
    - `GET /search/{short_id}/image` -- Serves annotated_photo BLOB as `Response(content=bytes, media_type="image/jpeg")`. Returns 404 if not found.
    - Set up Jinja2Templates pointing to `web_app/templates/`.
    - Add a background task (or startup event) that periodically cleans `_pending` dict entries older than 5 minutes.
    - CRITICAL: Import order in SSE generator -- use lazy imports inside the generator function to avoid circular imports (providers.manager, amazon_search, image_annotator).
