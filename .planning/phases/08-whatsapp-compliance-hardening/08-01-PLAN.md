Modify `adapters/whatsapp.py` to add window enforcement. All changes are inside `WhatsAppAdapter`:


2. **Add `_guard_window` async method** (place after `_is_window_open`):
   - Takes `chat_id: str`, returns `MessageRef | None`
   - Builds `user_key = f"whatsapp:{chat_id}"`
   - If `await self._is_window_open(user_key)` returns True: return None (proceed normally)
   - If window closed and `self._template_sent.get(chat_id, False)` is False:
     - Look up language: `lang_code = await database.get_user_lang(user_key) or "en"`
     - Call `await self.send_template(chat_id, template_name="product_results_ready", lang_code=lang_code)`
     - Set `self._template_sent[chat_id] = True`
     - Log at INFO: "WhatsApp 24h window closed for %s -- sent template re-engagement"
   - If window closed and template already sent:
     - Log at DEBUG: "WhatsApp 24h window closed for %s -- no-op (template already sent)"
   - Return `MessageRef(platform="whatsapp", chat_id=chat_id, message_id="", raw=None)`

3. **Guard `send_text`** — add at the very top of the method body (before assert):
   ```python
   guard = await self._guard_window(chat_id)
   if guard is not None:
       return guard
   ```

4. **Guard `send_photo`** — same pattern at top of method body:
   ```python
   guard = await self._guard_window(chat_id)
   if guard is not None:
       return guard
   ```

5. **Guard `send_list_message`** — same pattern at top of method body:

   ```python
   if guard is not None:
       return guard
   ```
