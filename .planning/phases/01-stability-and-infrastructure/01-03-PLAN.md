4. Create `gateway.py` with `create_app()` factory:
   ```python
   def create_app(webhook_adapters=None) -> FastAPI:
       app = FastAPI(title="Amazon Photo Bot", docs_url="/docs")

       # Security headers middleware
       @app.middleware("http")
       async def security_headers(request, call_next):
           response = await call_next(request)
           response.headers["X-Content-Type-Options"] = "nosniff"
           response.headers["X-Frame-Options"] = "DENY"
           return response

       # Health endpoint
       @app.get("/health")
       async def health():
           return {"status": "ok"}

       # Mount routers -- ORDER MATTERS
       from api_server import router as api_router
       app.include_router(api_router)  # /api/v1/...

       if webhook_adapters:
           from webhook_routes import router as webhook_router
           # Set adapters on the module or router state
           app.include_router(webhook_router)  # /webhook/{platform}

       from shortener_routes import router as shortener_router
       app.include_router(shortener_router)  # /{code} -- MUST BE LAST

       return app
   ```

1. In `main.py`, replace the aiohttp server startup with Uvicorn:
   - Remove `from aiohttp import web` and aiohttp runner setup.
   - Remove `from shortener_server import start_shortener` and `from webhook_server import create_webhook_app`.
   - Add:
     ```python
     from gateway import create_app
     import uvicorn

     gateway_app = create_app(webhook_adapters=webhook_adapters)
     uvi_config = uvicorn.Config(
         gateway_app,
         host="0.0.0.0",
         port=int(os.getenv("SHORTENER_PORT", "8080")),
         log_level="info",
         loop="none",  # Don't create a new event loop
     )
     server = uvicorn.Server(uvi_config)
     server_task = asyncio.create_task(server.serve())
     ```
   - Remove all `web_runner` and `webhook_runner` cleanup code.
   - In shutdown: `server.should_exit = True` then `await server_task`.

2. Implement graceful shutdown for in-flight tasks:
   - Create a module-level `_active_tasks: set[asyncio.Task] = set()` in `main.py` or a shared module.
   - When `analyse_image` is called from bot handlers, wrap it: `task = asyncio.create_task(...)`, add to `_active_tasks`, remove on completion via `task.add_done_callback`.
   - In the shutdown handler, after setting `server.should_exit = True`:
     ```python
     if _active_tasks:
         logger.info("Waiting for %d in-flight tasks...", len(_active_tasks))
         done, pending = await asyncio.wait(_active_tasks, timeout=10.0)
         if pending:
             logger.warning("Cancelling %d timed-out tasks", len(pending))
             for t in pending:
                 t.cancel()
     ```
   - Then proceed with PTB shutdown.
