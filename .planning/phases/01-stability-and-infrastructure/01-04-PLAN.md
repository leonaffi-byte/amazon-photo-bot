  <name>Task 2: Refactor admin.py to thin wrappers calling service layer</name>

1. Refactor each `_*_content()` function in `admin.py` to:
   - Call the corresponding `admin_service` function to get plain data.
   - Format the data into MarkdownV2 text and `InlineKeyboardMarkup` for Telegram.
   - The formatting logic stays in admin.py -- only the data fetching moves to admin_service.py.

   Example transformation:
   ```python
   # BEFORE:
   async def _tags_content() -> tuple[str, InlineKeyboardMarkup]:
       tags = await database.get_all_tags()
       # ... 30 lines of data processing + formatting ...
       return text, keyboard

   # AFTER:
   async def _tags_content() -> tuple[str, InlineKeyboardMarkup]:
       tags = await admin_service.list_tags()
       # ... formatting only, data comes from service ...
       lines = [f"Tag: {t.name} ({'active' if t.is_active else 'inactive'})" for t in tags]
       text = esc("\n".join(lines))
       keyboard = _build_tags_keyboard(tags)
       return text, keyboard
   ```

2. Refactor handler functions that do business logic inline (like `received_tag_name`, `received_key_value`, `received_setting_value`):
   - Move the DB write + validation into admin_service functions.
   - Keep only the Telegram conversation flow (getting user input, sending replies) in admin.py.

3. Add `import admin_service` at the top of admin.py.
