### Broken Flow

**Web Admin Initial Login via `/webtoken`**
- `main.py` generates fallback token at startup (line 211-213)
- Token stored in `admin_dashboard/auth.py` module state
- `/admin/login` POST `/auth/token` correctly verifies token
- **Break:** `TelegramAdapter.start()` does not register `CommandHandler("webtoken", ...)` — the handler exists only in legacy `bot.py`
- **Workaround:** Token printed to server startup logs; admin copies from console output
